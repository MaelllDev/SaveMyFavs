## 📖 Descrição
SaveMyFavs é uma extensão do Google Chrome projetada como conceito de um gerenciador moderno de favoritos.  
A ideia é oferecer uma interface simples e intuitiva para organizar links de forma prática.

---

## ✨ Funcionalidades Planejadas
- ➕ Adicionar novos favoritos manualmente  
- 📝 Editar ou remover favoritos existentes  
- 📂 Criar pastas para organizar os favoritos  
- 🔍 Barra de pesquisa para filtrar rapidamente  
- ↕️ Ordenação e organização via **drag & drop**  
- 🌐 Carregamento automático do **favicon** a partir da URL  
- 📤 Exportar favoritos em um arquivo de texto  
- 📥 Importar favoritos de volta para a extensão  
- 💾 Armazenamento local (JSON ou `chrome.storage`)  

---

## 🛠️ Estrutura do Projeto
- `manifest.json` → Configuração principal da extensão  
- `popup.html` → Interface da extensão  
- `popup.js` → Lógica de manipulação dos favoritos  
- `popup.css` → Estilização da interface  
- `storage.json` (simulado) → Salvamento dos favoritos
